# Synthetic Story Extraction Benchmarks

This document explains every column in the `canonarc` model extraction benchmark tables (generated by `ModelComparisonReport.to_markdown_table()` in [`tests/synthetic_story_library.py`](../tests/synthetic_story_library.py)) and presents the current cached model results across the 3K-token synthetic story suite.

---

## 1. Benchmark Setup & Guidance Modes

Each 3K-token benchmark story (`obsidian_signet_3k`, `chronos_station_3k`, `crimson_masquerade_3k`) consists of **6 narrative chunks** (~1,900–2,300 words) designed to exercise all 6 architectural tiers: spatial movement, mood/state deltas, directed social edges & register, disguise aliases, N-ary plot episodes with witness tracking, `InformDelta` deception/telling, and a non-destructive flashback at Step 4.

Models are evaluated under a **Guidance Mode** (`GuidanceMode`):
- **`none` (Unguided)**: The extractor receives only the prose chunk and the point-in-time active world registry (entity IDs, locations, artifacts, disguises, and prior episode IDs) at `step - 1`, with **no beat hints**. This is the primary test of real-world unassisted extraction.
- **`full_hints` (Beat-Guided)**: The extractor also receives per-chunk `extraction_hint` instructions specifying expected events, episode IDs, and state transitions. This measures schema compliance and instruction-following ceiling.
- **`canonical_episode_ids`**: Provides only canonical `episode_id` hints without full beat instructions.

## 2. Column-by-Column Explanation

| Column | Source Field | How It Is Computed & What It Measures |
| :--- | :--- | :--- |
| **Model** | `extraction_model` | Identifier of the LLM or deterministic extractor evaluated (e.g., `gemini-4-hydrogen`, `qwen/qwen3.6-27b`, `deepseek-flash`, `qwen/qwen3.5-9b`, `rule-based-non-llm`). |
| **Run Status** | `skipped_cached_run` | `RAN` if the benchmark executed live during the comparison run, or `SKIPPED (Cached)` if loaded from a matching `(model, prompt, story)` cache on disk. |
| **Overall Quality** | `overall_quality_score` | Weighted composite score (`0.0%–100.0%`) across five category subscores:<br>• **30%** `epistemic_score` (`0.35 * witness_f1 + 0.25 * (1 - epistemic_leak_rate) + 0.25 * inform_delta_f1 + 0.15 * disguise_accuracy`)<br>• **25%** `spatial_state_score` (`0.35 * room_occupancy_jaccard + 0.25 * location_delta_f1 + 0.25 * mood_soft_accuracy + 0.15 * mood_delta_f1`)<br>• **20%** `pov_retrieval_score` (`0.30 * pov_entity_jaccard + 0.30 * pov_episode_recall + 0.40 * max(0, 1 - 0.20 * pov_secret_leak_count)`)<br>• **15%** `edge_flashback_score` (`0.50 * edge_delta_f1 + 0.20 * causal_link_accuracy + 0.30 * (1.0 if flashback_guard_passed else 0.0)`)<br>• **10%** `schema_hygiene_score` (`0.50 * first_pass_valid_rate + 0.50 * max(0, 1 - hallucinated_id_rate)`) |
| **Strict Checks** | `pass_rate` (`checks_passed / checks_total`) | Percentage of hard E2E test assertions passed (out of `50` checks per 6-chunk story). Unlike `Overall Quality`, strict checks require exact string matches (e.g., exact mood labels) and exact step-by-step invariants. |
| **Room Occ. Jaccard** | `room_occupancy_jaccard` | Mean Jaccard similarity (`\|expected ∩ actual\| / \|expected ∪ actual\|`) across all rooms and all steps when querying `retrieve_context(location_id=room_id)` for which characters are physically in each room. |
| **Loc Delta F1** | `location_delta_f1` | Step-local F1 score on `(entity_id, location_id)` movement deltas. Idempotent re-assertions of a character's already-correct current room are not penalized as false positives. |
| **Mood Soft Acc** | `mood_soft_accuracy` | Fraction of `(step, character)` mood checks where the extracted mood matches the oracle mood either exactly or via semantic synonym clusters (`moods_soft_match()`, e.g., `"furious"` vs. `"cold fury"`). |
| **Witness F1** | `witness_f1` | Micro-averaged F1 score across all aligned plot episodes comparing extracted `witnesses` against oracle `witnesses`. |
| **Silent Witness** | `silent_witness_recall` | Recall of **non-active** witnesses—characters who are physically present and witness an episode without being an `actor`, `target`, or `experiencer` in `participants`. Tests whether the model infers co-present observers rather than copying only active participants. |
| **Epistemic Leaks** | `epistemic_leak_count` | Raw count of absent characters (characters not in the oracle `witnesses` set) erroneously included in an episode's `witnesses` list during extraction. Lower is better (`0` is ideal). |
| **Inform F1** | `inform_delta_f1` | F1 score on `(aligned_episode_id, entity_id, epistemic)` `InformDelta` triples (e.g., `"told"`, `"deceived"`, `"forgotten"`), measuring how accurately secondhand knowledge transfer and deception are extracted. |
| **POV Secret Leaks** | `pov_secret_leak_count` | Downstream retrieval leak count across all per-character `retrieve_context(pov_entity_ids=[cid])` queries at every step. Increments whenever:<br>1. An oracle-hidden episode is returned in the model engine's POV context, **or**<br>2. A disguised character that is `masked:<id>` in the oracle POV context is leaked unmasked (`<id>`) in the model engine's POV context. Lower is better (`0` is ideal). |
| **Flashback Guard** | `flashback_guard_passed` | `PASS` or `FAIL`. Verifies that at Step 4 (the flashback chunk), the model sets `is_flashback=True` **and** does not overwrite the protagonist's present-day mood (`"furious"`) with their past flashback mood (`"naive_trusting"`). |
| **Hallucinated IDs** | `hallucinated_id_count` (`hallucinated_id_rate`) | Number (and percentage of total raw extracted IDs) of entity/location/artifact IDs in the pre-normalization `raw_delta` that are neither canonical IDs nor known surface/alias names. Lower is better (`0 (0%)` is ideal). |
| **Retries** | `total_retries` | Total number of LLM extraction retry attempts triggered by schema/validation failures across the story. |
| **Tokens** | `total_tokens` | Total historical extraction API tokens (prompt + completion) consumed across all chunks of the story. |
| **Latency (s)** | `latency_ms / 1000.0` | Total extraction wall-clock latency in seconds across the story (`0.0s` when loaded from pre-existing extraction cache without timing metadata). |
| **Est. Cost (USD)** | `estimate_cost_usd()["total_cost_usd"]` | Estimated total API cost in USD for the extraction run based on token usage and model pricing metadata. |

## 4. Key Takeaways

1. **Unguided (`none`) separates model tiers sharply**: With beat hints (`full_hints`), all four LLMs reach **99.2%–100.0%** `Overall Quality`. Without hints (`none`), `gemini-4-hydrogen` leads at **94.7%** (`90.0%` strict, `85.7%` `Inform F1`, `100.0%` `Edge Delta F1`), followed by `qwen/qwen3.6-27b` (**86.5%**, `0` POV secret leaks), `deepseek-flash` (**84.8%**), `qwen/qwen3.5-9b` (**70.0%**), and `rule-based-non-llm` (**56.2%**).
2. **Epistemic & `InformDelta` tracking is the primary differentiator**: Every LLM kept `Hallucinated IDs` at `0 (0%)` and passed `Flashback Guard`, whereas `Inform F1` in unguided mode ranged from `85.7%` (`gemini-4-hydrogen`) down to `40.0%` (`deepseek-flash`) and `0.0%` (`rule-based-non-llm`).
3. **Rule-based baseline**: `rule-based-non-llm` runs in `< 10ms` at `$0` cost and passes `Flashback Guard`, but cannot infer movement (`Loc Delta F1 = 0.0%–25.0%`) or `InformDelta` deception/telling (`0.0%–40.0%`), resulting in `8–14` downstream `POV Secret Leaks`.
