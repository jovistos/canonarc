### 1.2 Guidance Modes (`GuidanceMode`)

- **`none` (Unguided with Canonical Registry)**: The extractor receives the prose chunk and the point-in-time active world registry (entity IDs, locations, artifacts, disguises, and top-$K$ prior episode IDs) at `step - 1`, with **no beat hints**.
- **`surface_only` (Zero-ID Natural-Names Mode)**: The extractor receives only natural character names (`"Elena"`), location names (`"Council Chamber"`), artifact names (`"Obsidian Signet"`), and prior episode summaries—**no internal `char_*`, `loc_*`, or `item_*` IDs are exposed**. This directly benchmarks how well the model emits clean surface names and how effectively `engine.normalize_delta()` + `DefaultLexicalResolver` link them back to canonical IDs.
- **`canonical_episode_ids`**: Provides only canonical `episode_id` hints without beat instructions.
- **`full_hints` (Beat-Guided)**: Provides per-chunk `extraction_hint` instructions specifying expected events, episode IDs, and state transitions to measure schema compliance ceiling.

## 2. Column-by-Column Explanation

| Column | Source Field | How It Is Computed & What It Measures |
| :--- | :--- | :--- |
| **Model** | `extraction_model` | Identifier of the LLM, generic rule-based baseline (`rule-based-non-llm`), or null inertia baseline (`noop-null-baseline`). |
| **Run Status** | `skipped_cached_run` | `RAN` if executed/scored during the run, or `SKIPPED (Cached)` if loaded from a matching `(model, prompt, story)` benchmark signature on disk. |
| **Overall Quality** | `overall_quality_score` | Weighted composite score (`0.0%–100.0%`) across five category subscores:<br>• **30%** `epistemic_score` (`0.30 * witness_f1 + 0.25 * (1 - epistemic_leak_rate) + 0.20 * inform_delta_f1 + 0.10 * deception_summary_accuracy + 0.15 * disguise_accuracy`)<br>• **25%** `spatial_state_score` (`0.35 * room_occupancy_jaccard + 0.25 * location_delta_f1 + 0.25 * mood_soft_accuracy + 0.15 * mood_delta_f1`)<br>• **20%** `pov_retrieval_score` (`0.30 * pov_entity_jaccard + 0.30 * pov_episode_recall + 0.40 * max(0, 1 - 0.20 * pov_secret_leak_count)`)<br>• **15%** `edge_flashback_score` (`0.40 * edge_delta_f1 + 0.15 * voice_register_accuracy + 0.15 * causal_link_accuracy + 0.30 * (1.0 if flashback_guard_passed else 0.0)`)<br>• **10%** `schema_hygiene_score` (`0.50 * first_pass_valid_rate + 0.50 * max(0, 1 - hallucinated_id_rate)`) |
| **Strict Checks** | `pass_rate` (`checks_passed / checks_total`) | Combined percentage of hard E2E test assertions passed across the story (calibrated with `moods_soft_match()` on cumulative mood checks). |
| **Step-Delta Checks** | `step_delta_pass_rate` | Percentage of **step-local transition assertions** passed (disguise masking/piercing, secret confrontation isolation, flashback non-overwrite guard, deception recall, secondhand truth overturning, memory suppression, consolidation, and branching). Decoupled from cumulative state drift. |
| **Cumulative State** | `cumulative_state_pass_rate` | Percentage of **accumulated room-occupancy and character-mood assertions** passed across all rooms and characters at every step (`moods_soft_match()` + prose-supported `acceptable_moods`). |
| **Room Occ. Jaccard** | `room_occupancy_jaccard` | Mean **occupied-room** Jaccard similarity (`\|expected ∩ actual\| / \|expected ∪ actual\|` over non-empty rooms, preventing empty-room `1.0` inflation) alongside per-character `character_location_accuracy`. |
| **Loc Delta F1** | `location_delta_f1` | Step-local F1 score on `(entity_id, location_id)` movement deltas (ignoring idempotent re-assertions of already-correct rooms). |
| **Mood Soft Acc** | `mood_soft_accuracy` | Fraction of `(step, character)` mood checks matching the oracle mood via negation-aware token synonym clusters (`moods_soft_match()`, which rejects negated forms like `"not calm"` or `"uncalm"`). |
| **Witness F1** | `witness_f1` | Micro-averaged F1 score across semantically aligned plot episodes (combining participant/witness overlap, predicate, location, and summary token overlap $\ge 0.35$) comparing extracted `witnesses` against oracle `witnesses`. |
| **Silent Witness** | `silent_witness_recall` | Recall of **non-active** co-present witnesses (`witnesses` who are not `actor`, `target`, or `experiencer`). |
| **Epistemic Leaks** | `epistemic_leak_count` | Raw count of absent characters erroneously included in an episode's `witnesses` list (`0` is ideal). |
| **Inform F1** | `inform_delta_f1` | F1 score on `(aligned_episode_id, entity_id, epistemic)` `InformDelta` triples (`"told"`, `"deceived"`, `"forgotten"`), with content-verified `deception_summary_accuracy` (must match cover-story tokens and not leak ground-truth secret terms). |
| **Voice Reg. Acc** | `voice_register_accuracy` | Tier 5 dyadic voice register retrieval accuracy comparing the model engine's active speaker-to-addressee `register` (`ti` vs `Vi`) against the oracle engine at voice-bearing steps. |
| **POV Secret Leaks** | `pov_secret_leak_count` | Downstream retrieval leak count across per-character `retrieve_context(pov_entity_ids=[cid])` queries at every step (`0` is ideal). |
| **Flashback Guard** | `flashback_guard_passed` | `PASS` or `FAIL`. Verifies that flashback chunks (`is_flashback=True`) preserve the protagonist's prior present-day mood instead of overwriting it with past flashback mood (`"naive_trusting"`). |
| **Hallucinated IDs** | `hallucinated_id_count` (`hallucinated_id_rate`) | Number (and percentage) of pre-normalization raw extracted IDs that are neither canonical IDs (including dynamically introduced mid-story entities) nor registered surface/alias names (`0 (0%)` is ideal). |
| **Est. Cost (USD)** | `estimate_cost_usd(model=...)` | Model-aware API cost estimate via `MODEL_PRICING_PER_1M_USD` (`$0.00` for local LM Studio / Ollama / rule-based / null baselines; `$0.10/$0.40` per 1M for `gemini-4-hydrogen`; `$0.14/$0.28` per 1M for `deepseek-flash`). Cached runs without recorded wall-clock latency display `n/a (cached)`. |
